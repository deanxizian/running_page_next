# References and Credits

## Implementation

- [yihong0618/running_page](https://github.com/yihong0618/running_page) — upstream foundation for Strava synchronization, activity processing, and the original dashboard.
- [AnmolSaini16/mapcn](https://github.com/AnmolSaini16/mapcn) — reference for the MapLibre and CARTO map integration.

## Maps and Geographic Data

- [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) — browser map renderer.
- [CARTO Basemap Styles](https://github.com/CartoDB/basemap-styles) and [OpenStreetMap](https://www.openstreetmap.org/copyright) — basemap styling, vector tiles, and map data.
- [world-geo-json-zh](https://github.com/Autmlif/world-geo-json-zh) — Chinese world boundary data bundled with the site.

## APIs and Assets

- [Strava API](https://developers.strava.com/) and [stravalib](https://github.com/stravalib/stravalib) — activity data and API client.
- [Nominatim](https://github.com/osm-search/Nominatim) — reverse geocoding.
- [Open-Meteo](https://github.com/open-meteo/open-meteo) — historical race weather.
- [IBM Plex](https://github.com/IBM/plex) — interface typefaces.
